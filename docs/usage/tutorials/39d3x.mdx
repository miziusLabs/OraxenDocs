# 🪽 Creating an Elytra

## Overview
Custom elytra textures require Minecraft `1.21.2` or newer and `custom-armor.type: COMPONENT` in `settings.yml`. The `equipment.wings` texture is visible while worn. The `pack` section controls how the elytra looks in the inventory. For all equipment options, see [Armor](/configuration/items/behavior/armor).

## Tutorial

<Steps>

### Create the Elytra item
Create a new item in the items folder (or edit an existing `.yml` file).

```yaml
amethyst_elytra:
  name: "<gradient:#9B59B6:#5B6BBF:#1A237E>Amethyst Elytra</gradient>"
  material: ELYTRA
  components:
    max_stack_size: 1
  equipment:
    wings: default/armors/amethyst_elytra
  pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - default/armors/amethyst_elytra_icon
```

### Adding the textures / models
Place your icon at `plugins/Oraxen/pack/textures/default/armors/amethyst_elytra_icon.png`.

Place your Elytra texture at `plugins/Oraxen/pack/textures/default/armors/amethyst_elytra.png`.


### Reload and regenerate pack
Run `/oraxen reload all` and then give yourself the item via `/oraxen give @s amethyst_elytra` (or get it from `/oraxen inv`).
</Steps>

## Troubleshooting
- Missing texture in inventory - check `pack.textures` and icon file path.
- Texture in inventory works, but worn Elytra is wrong - check `equipment.wings` and `amethyst_elytra.png` file path.
- No visible changes - reload Oraxen and re-apply the generated resource pack.
