# 🛡️ Creating custom armor using trims

## Overview
This tutorial demonstrates how to create a custom armor set using Oraxen's armor-trim system.
Trim-based armor supports Minecraft 1.20.1 through 1.21.1. Use [component-based armor](/usage/tutorials/h2k8m) on 1.21.2 and later. For all equipment options, see [Armor](/configuration/items/behavior/armor).

## Tutorial

<Steps>

### Enable trim-based armor

Open `plugins/Oraxen/settings.yml` and configure the `custom-armor` section.

```yaml
custom-armor:
  type: TRIMS
  trims:
    material-replacement: CHAINMAIL
```

`custom-armor.trims.material-replacement` is the vanilla armor material Oraxen reserves for custom trim armor. It defaults to `CHAINMAIL`. Valid materials are `CHAINMAIL`, `IRON`, `GOLD`, `DIAMOND`, `NETHERITE`, and `LEATHER`.

Every piece must use the configured material. `CHAINMAIL` is recommended because it has no normal crafting recipe.

### Add the textures

Add the worn textures and inventory icons as described in the [component-based armor tutorial](/usage/tutorials/h2k8m#add-the-textures).

### Configure the armor items

Create the four armor pieces in `plugins/Oraxen/items/sapphire_armor.yml` as described in [Configure the armor items](/usage/tutorials/h2k8m#configure-the-armor-items). Use the same `CHAINMAIL` materials and `equipment` setup, which match `custom-armor.trims.material-replacement`.

Oraxen assigns the `oraxen:sapphire` trim from the `humanoid` and `humanoid_leggings` layers and applies it automatically to pieces with the same `equipment.id`.

### Generate the resource pack and datapack

Save the files and run the following command.

```text
/oraxen reload all
```

Oraxen generates the `oraxen:sapphire` pattern and the `oraxen_trim_armor` datapack. Fully restart the server after generating the datapack for the first time; Minecraft's `/reload` command is not sufficient. Check `/datapack list` and, if necessary, enable the datapack with this command.

```text
/datapack enable "file/oraxen_trim_armor"
```

Restart the server again after enabling the datapack.

</Steps>

## Troubleshooting

If equipped armor appears vanilla or the trim is missing, verify that `custom-armor.type` is `TRIMS`, the pieces use the configured replacement material, every piece uses the same `equipment.id`, the datapack is enabled, and the server has been fully restarted. Trim armor must use real armor items such as `CHAINMAIL_HELMET`, not `PAPER`. Other layers, including wings and mob armor, do not work in this mode.
