# 🛡️ Creating custom armor using components

## Overview
This tutorial demonstrates how to create a custom armor set using Minecraft's equippable component.
Component-based armor requires Minecraft `1.21.2+`. For older versions, use the [armor trims tutorial](/usage/tutorials/g7p4t). For all equipment options, see [Armor](/configuration/items/behavior/armor).

## Tutorial
<Steps>

### Enable component-based armor

Open `plugins/Oraxen/settings.yml` and set the armor type to `COMPONENT`.

```yaml
custom-armor:
  type: COMPONENT
```

### Add the textures

Add two transparent worn textures, typically `64x32` pixels.

- `sapphire_layer_1.png` contains the helmet, chestplate, and boots.
- `sapphire_layer_2.png` contains the leggings.

```text
plugins/Oraxen/pack/textures/armor/sapphire_layer_1.png
plugins/Oraxen/pack/textures/armor/sapphire_layer_2.png
```

Add an inventory icon, typically `16x16` pixels, for each piece in the same folder.

```text
sapphire_helmet.png
sapphire_chestplate.png
sapphire_leggings.png
sapphire_boots.png
```

### Configure the armor items

Create `plugins/Oraxen/items/sapphire_armor.yml` and add all four pieces.

```yaml
sapphire_helmet:
  name: "<gradient:#ff1744:#9c0025>Sapphire Helmet</gradient>"
  material: CHAINMAIL_HELMET
  equipment:
    id: sapphire
    humanoid: armor/sapphire_layer_1
    humanoid_leggings: armor/sapphire_layer_2
  pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - armor/sapphire_helmet

sapphire_chestplate:
  name: "<gradient:#ff1744:#9c0025>Sapphire Chestplate</gradient>"
  material: CHAINMAIL_CHESTPLATE
  equipment:
    id: sapphire
  pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - armor/sapphire_chestplate

sapphire_leggings:
  name: "<gradient:#ff1744:#9c0025>Sapphire Leggings</gradient>"
  material: CHAINMAIL_LEGGINGS
  equipment:
    id: sapphire
  pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - armor/sapphire_leggings

sapphire_boots:
  name: "<gradient:#ff1744:#9c0025>Sapphire Boots</gradient>"
  material: CHAINMAIL_BOOTS
  equipment:
    id: sapphire
  pack:
    generate_model: true
    parent_model: "item/generated"
    textures:
      - armor/sapphire_boots
```

Use the same `equipment.id` on every piece and set each inventory icon in `pack.textures`. Only the helmet needs to define `humanoid` and `humanoid_leggings`.

### Generate and apply the resource pack

Save the files and run the following command.

```text
/oraxen reload all
```

Reapply the generated pack, then get the pieces from `/oraxen inv` or `/oraxen give @s <item_id>`.

</Steps>

## Troubleshooting

If equipped armor is invisible or looks vanilla, check the following.

- The server runs Minecraft `1.21.2` or newer.
- `custom-armor.type` is set to `COMPONENT`.
- Every piece uses the same `equipment.id`, and the helmet points to `armor/sapphire_layer_1` and `armor/sapphire_layer_2`.
- You reloaded Oraxen and reapplied the regenerated resource pack.
