# 🖱️ DeluxeMenus

## Overview
DeluxeMenus can use Oraxen items as menu slot materials. This is handled by DeluxeMenus, so no additional Oraxen configuration is required.

## Usage
Set the slot material to `oraxen-oraxen_item_id`, replacing `oraxen_item_id` with the ID of your Oraxen item.

```yaml
items:
  example_item:
    material: oraxen-my_custom_item
    slot: 0
```

For all supported material options, see the [DeluxeMenus material documentation](https://wiki.helpch.at/helpchat-plugins/deluxemenus/options-and-configurations/item#material).
