# 🛡️ Armor

## Overview
Oraxen lets you create custom armor, elytras, mob armor, saddles, and harnesses using the `equipment` section.

<img src="/assets/armors/layer.png" alt="An armor layer texture." width="650"/>

## Configuration
Armor is configured as items in `.yml` files inside the `plugins/Oraxen/items` folder.

```yml
sapphire_helmet:
  material: CHAINMAIL_HELMET
  equipment:
    id: sapphire # Shared texture set for this item.
    humanoid: armor/sapphire_layer_1 # Worn helmet, chestplate, and boots texture.
    humanoid_leggings: armor/sapphire_layer_2 # Worn leggings texture.
  pack:
    generate_model: true
    parent_model: item/generated
    textures:
      - armor/sapphire_helmet # Inventory icon.

sapphire_chestplate:
  material: CHAINMAIL_CHESTPLATE
  equipment:
    id: sapphire # Shares the helmet's texture set.
```

### Appearance

- Use [`pack`](/configuration/items/appearance) for the item model and inventory icon.
- Use `equipment.humanoid` for the worn helmet, chestplate, and boots texture.
- Use `equipment.humanoid_leggings` for the worn leggings texture.
- Use the same `equipment.id` across pieces to share a texture set, so you only need to define each layer once.

When `equipment.id` is omitted, Oraxen uses the item ID. IDs can contain lowercase letters, numbers, dots, underscores, and hyphens, with no namespace.

For example, `armor/sapphire_layer_1` refers to `plugins/Oraxen/pack/textures/armor/sapphire_layer_1.png`. Texture paths use the same format as `pack.textures` and can also reference files in uploaded packs.

### Components

Use `custom-armor.type: COMPONENT` in [`settings.yml`](/usage/settings) on Minecraft 1.21.2 or newer.

- The equipment model defaults to `oraxen:<id>`.
- The equipment slot comes from the base material. If the material has no default slot, `wings` uses `CHEST`, body layers use `BODY`, and saddle layers use `SADDLE`. For a non-armor material such as `PAPER` with only humanoid layers, set `components.equippable.slot`.
- For body and saddle slots, Oraxen determines which mobs can wear the item from its configured layers. Pieces that reference a shared `equipment.id` inherit that set's layers.
- Any [`equippable` component settings](/configuration/items/data/components) you define are preserved, and Oraxen copies defaults such as equip sounds from the base material when available.

If the merged pack contains `assets/oraxen/equipment/<id>.json`, Oraxen uses that file instead of generating one. On Minecraft 1.21.2 and 1.21.3, the path is `assets/oraxen/models/equipment/<id>.json`.

### Layers

| Layer | Minimum Minecraft version |
| --- | --- |
| `humanoid`, `humanoid_leggings`, `wings`, `wolf_body`, `horse_body`, `llama_body` | 1.21.2 |
| `pig_saddle`, `strider_saddle`, `camel_saddle`, `horse_saddle`, `donkey_saddle`, `mule_saddle`, `skeleton_horse_saddle`, `zombie_horse_saddle` | 1.21.5 |
| `happy_ghast_body` | 1.21.6 |
| `nautilus_body`, `nautilus_saddle`, `camel_husk_saddle` | 1.21.11 |
| `humanoid_baby` | 26.1 |

Oraxen logs and skips any layer the server version does not support.

For example, use `happy_ghast_body` to give a harness its worn texture.

```yaml
amethyst_harness:
  material: PAPER
  equipment:
    happy_ghast_body: armor/amethyst_harness
```

For a complete elytra example, see [Creating an Elytra](/usage/tutorials/39d3x).

### Trims

Use `custom-armor.type: TRIMS` in [`settings.yml`](/usage/settings) on Minecraft 1.20.1 through 1.21.1.

- Set each piece's material to the material configured in `custom-armor.trims.material-replacement`, which defaults to `CHAINMAIL`.
- Oraxen generates and assigns the `oraxen:<id>` trim from `humanoid` and `humanoid_leggings`, and adds the `HIDE_ARMOR_TRIM` item flag.
- Other layers, such as wings and mob armor, are not supported in trim mode.
